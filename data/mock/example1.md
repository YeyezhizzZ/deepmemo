# DeepMemo 项目介绍

## 产品定位

DeepMemo 是一个面向个人 Markdown 知识库的管理与创作工作台。

## 演示数据中的模式功能解析

在 DeepMemo 中，编辑器模式和问答模式各司其职，共同构成了创作-检索的闭环：

1. 编辑器模式

核心职能：内容管理与生产。

具体表现：它直接映射你的 data/ 目录。你可以在这里像使用 Obsidian 或 VS Code 一样，直接对 Markdown 文件进行增删改查。它是知识库的输入端，确保你的唯一真值持续更新。

2. 问答模式 (Q&A Mode)

核心职能：知识激活与消费。

具体表现：这是你与知识库对话的地方。系统不再让你手动翻找文件，而是通过 LocalSearchAgent 检索相关片段，并由 LLM 整理成逻辑清晰的回答。

关键特征：所有的回答都带有溯源引用（如 [1]），点击即可在侧边栏查看原始文件的行号和上下文。

## 示例流程
1. 用户在问答模式里提出问题。
2. LocalSearchAgent 使用关键词检索 Markdown 文件，读取命中的上下文片段。
3. AnswerComposer 把用户问题、对话历史和本地证据组合给 LLM。
4. 回答会用 `[1]`、`[2]` 这样的编号标注引用来源，方便在右侧来源面板追溯原文。
