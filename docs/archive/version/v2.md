# V2 版本说明

## 概述

V2 是 DeepMemo 的重大升级版本，从"知识库问答助手"转变为"文件系统驱动的知识创作工作站"。

**核心变化**：以物理磁盘的 `.md` 文件为唯一真值，通过 SQLite 维护文件元状态，前端实现编辑器模式与问答模式双切换。

---

## 技术栈

| 层级 | V1 | V2 |
|------|----|----|
| 前端框架 | React | React 18+ (Vite) |
| 样式 | 普通 CSS | Tailwind CSS |
| 状态管理 | React State | Zustand |
| 后端 | FastAPI | FastAPI (模块化) |
| 数据库 | SQLite | SQLite (增强 Schema) |
| 文件监听 | 无 | Watchdog |

---

## 功能特性

### 后端 (backend_v2.md)
- **文件系统即数据库**：`.md` 文件是知识唯一真值
- **SQLite 增强**：
  - `file_meta` 表：文件路径、hash、sync_status、last_modified
  - `message` 表：增加 `citations` 字段存储指纹化引用
- **FS API**：tree、content、write、move、create-file、create-directory、sync-status
- **Chat API**：支持 citations 返回
- **Pulse API**：`/api/pulse/today` 聚合 Git Commits 和 raw 素材
- **Watcher**：监听文件变化，自动更新 file_meta 状态

### 前端 (frontend_v2.md)
- **双模式切换**：编辑器模式 / 问答模式
- **左侧文件树**：带 sync_status 状态灯，支持新建文件/文件夹、重命名
- **编辑器视图**：Markdown 编辑，支持 Slash Command、@实体链接
- **对话视图**：标准问答流
- **右侧面板**：
  - Source Panel：指纹化引用，消息分组
  - Daily Pulse：Git Commits、Raw 素材

## 关键设计

### 文件状态机
```
synced → dirty → synced
  ↓
 (error)
```

### Watcher 流程
1. 监听 `.md` 文件变化
2. 计算文件新 Hash
3. 与数据库中 hash 对比
4. 不同则更新 `file_meta.sync_status = 'dirty'`
5. 触发 `on_change_callback` 通知前端

## V1 → V2 迁移

| 维度 | V1 | V2 |
|------|----|----|
| 数据存储 | 仅 SQLite | SQLite + 物理文件 |
| 前端状态 | Mock 数据 | 真实 API 驱动 |
| 文件管理 | 无 | 完整 CRUD + 状态同步 |
| 知识引用 | 无 | Citations 指纹化引用 |
| 创作模式 | 仅问答 | 编辑器 + 问答双模式 |
| 上下文聚合 | 无 | Git Commits + Raw 素材 |
