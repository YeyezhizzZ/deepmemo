# 架构设计
框架：react
编程语言：ts
构建工具：vite 

# 页面设计
做知识库问答助手的前端界面，按钮绑定 mock 数据。

## 页面定位
这是一个面向知识库检索、问答和资料追溯的工作台，不做营销首页。首屏直接进入可用的问答界面，让用户能够立刻选择知识库、输入问题、查看回答和引用来源。

## 整体风格
- 风格关键词：专业、安静、高效、可信。
- 视觉密度：偏工作台，不做大面积装饰图、不做夸张渐变、不做卡片堆叠。
- 主色建议：深海蓝 `#1E3A5F`，强调色 `#2F80ED`，成功色 `#16A34A`，警告色 `#D97706`，错误色 `#DC2626`。
- 背景色：页面背景 `#F5F7FA`，主内容背景 `#FFFFFF`，侧边栏背景 `#EEF3F8`。
- 文字色：主文字 `#172033`，次级文字 `#5B667A`，弱提示 `#8A94A6`。
- 边框色：`#DDE3EA`，hover 边框 `#AFC2D8`。
- 圆角：常规控件 `6px`，卡片或面板 `8px`，不要使用过大的胶囊形圆角。
- 阴影：只在弹窗、悬浮菜单、输入框聚焦时使用轻阴影，主布局不依赖阴影分层。

## 页面布局
采用三栏工作台结构：

1. 左侧知识库导航栏
   - 宽度约 `260px`，固定在左侧。
   - 顶部显示产品名 `DeepMemo` 和当前环境标识。
   - 包含知识库列表、最近会话、标签筛选入口。
   - 知识库项展示名称、文档数量、更新时间、选中状态。
   - 底部放置设置、数据导入、用户入口。

2. 中间问答主区域
   - 使用自适应宽度，占据页面主要空间。
   - 顶部工具条展示当前知识库、检索模式、刷新按钮、清空会话按钮。
   - 中部是消息流，用户问题靠右，助手回答靠左。
   - 回答内容需要支持段落、列表、引用标记和代码块样式。
   - 底部固定输入区，包含多行输入框、发送按钮、上传/引用按钮、检索范围选择。

3. 右侧来源与上下文面板
   - 宽度约 `340px`，可折叠。
   - 展示当前回答引用的文档片段、相似度、文件名、更新时间。
   - 支持点击来源后高亮对应回答引用。
   - 空状态展示“等待回答后显示引用来源”，不要放大段说明文案。

## 关键组件样式

### 顶部工具条
- 高度 `56px`，白底，下边框 `1px solid #DDE3EA`。
- 左侧展示当前知识库名称和状态标签。
- 右侧使用图标按钮：刷新、导出、清空、折叠右栏。
- 图标建议使用 `lucide-react`，按钮尺寸 `32px`，hover 背景 `#EEF3F8`。

### 知识库列表
- 列表项高度 `56px` 到 `64px`。
- 选中项使用左侧 `3px` 主色竖线和浅蓝背景。
- 文档数量、更新时间用小字号次级文字。
- 鼠标悬停时背景变为 `#E6EEF7`。

### 消息流
- 消息区内边距 `24px`。
- 消息最大宽度 `760px`。
- 用户消息使用浅蓝背景 `#EAF3FF`，右对齐。
- 助手消息使用白底和细边框，左对齐。
- 不在消息外再套大卡片，避免卡片嵌套。
- 回答中的引用使用 `[1]`、`[2]` 形式，蓝色可点击，hover 下划线。
- 加载状态使用三点动画或骨架行，不使用大段解释文字。

### 输入区
- 固定在中间区域底部，白底，上边框 `1px solid #DDE3EA`。
- 输入框最小高度 `64px`，最大高度 `180px`，超过后内部滚动。
- 发送按钮使用主色实心按钮，禁用时降低透明度。
- 上传、选择知识库、切换检索模式使用图标按钮或紧凑选择器。
- 输入框获得焦点时边框变为强调色，出现轻微外发光。

### 右侧来源面板
- 每个来源是一张独立小卡片，圆角 `8px`，边框 `#DDE3EA`。
- 卡片内展示标题、来源类型、片段摘要、相似度标签。
- 相似度标签颜色：
  - 高：绿色浅底
  - 中：蓝色浅底
  - 低：灰色浅底
- 当前选中的来源卡片使用强调色边框。

## 页面状态
- 初始状态：中间区域展示紧凑的空会话提示、三个示例问题按钮、底部输入框。
- 问答中：发送按钮进入 loading，输入框可继续输入但发送禁用。
- 回答完成：消息流新增回答，右侧更新引用来源。
- 无结果：助手回答说明没有找到可靠资料，右侧展示空来源状态。
- 错误状态：使用顶部或输入区附近的轻量错误提示，不弹出阻断式弹窗。

## Mock 交互
- 知识库切换按钮绑定 mock 知识库列表。
- 示例问题按钮点击后自动填充并触发 mock 回答。
- 发送按钮根据输入内容匹配 mock 回答：
  - 包含“部署”时返回部署相关回答。
  - 包含“权限”时返回权限相关回答。
  - 其他问题返回通用知识库回答。
- 来源面板使用 mock 文档片段，包含文件名、相似度、更新时间。
- 刷新按钮模拟重新检索，显示短暂 loading。
- 清空按钮清除当前 mock 会话。

## 响应式设计
- 桌面端：三栏布局完整展示。
- 平板端：左侧栏压缩为图标导航，右侧来源面板默认折叠。
- 移动端：单栏布局，知识库列表和来源面板通过抽屉打开。
- 移动端输入区固定底部，按钮保持可点击尺寸不小于 `40px`。

## 实现约束
- 使用 React 组件拆分：`Sidebar`、`TopBar`、`ChatPanel`、`MessageList`、`Composer`、`SourcesPanel`。
- 使用 TypeScript 定义 mock 数据类型：知识库、消息、来源文档、检索模式。
- 样式可以先用普通 CSS 或 CSS Modules，保持 Vite 默认工程容易启动。
- 所有按钮先绑定本地 mock 数据，不接真实接口。
- 页面首屏就是问答工作台，不做 landing page。
