# V1 版本说明

## 概述

V1 是 DeepMemo 的初始版本，实现了一个基础的本地知识库问答助手。

**核心定位**：不做多用户，MVP 版本所有会话共享同一个数据库。

---

## 技术栈

| 层级 | 技术选型 |
|------|----------|
| 前端 | React + TypeScript + Vite |
| 后端 | Python + FastAPI |
| 数据库 | SQLite |
| LLM | OpenAI SDK |
| 配置 | `config/llm_api.yaml` |

---

## 功能特性

### 后端 (backend.md)
- **Session 管理**：创建、查询、删除会话
- **消息存储**：支持 user/ai 角色的消息，以 Markdown 格式存储
- **SQLite Schema**：
  - `session` 表：session_id, session_name, message_ids (JSON), created_at, updated_at
  - `message` 表：message_id, session_id, role, content, created_at

### 前端 (frontend.md)
- **三栏工作台布局**：
  - 左侧：知识库导航栏 (~260px)
  - 中间：问答复区域（自适应）
  - 右侧：来源与上下文面板 (~340px)
- **页面状态**：初始状态、问答中、回答完成、无结果、错误状态
- **响应式设计**：桌面端/平板端/移动端适配
- **Mock 交互**：按钮绑定 mock 数据，不接真实接口

### 设计风格
- **主色**：深海蓝 `#1E3A5F`
- **强调色**：#2F80ED
- **风格关键词**：专业、安静、高效、可信

---

## 约束与限制

1. 不做用户认证
2. 不做多租户/多用户
3. 前端使用 Mock 数据，不连接真实后端
4. session 和 message 的 ID 使用 UUID v4
